# Programas Básicos em COBOL

Repositório dedicado ao estudo e prática da linguagem COBOL.

## Programas Incluídos

* **`main.cob` / `hello.cob`**: Programa inicial para exibição de mensagem no terminal.
* **`comovai.cob`**: Programa interativo que recebe o nome do utilizador via `ACCEPT`, obtém a data atual do sistema (`YYYYMMDD`) e exibe uma mensagem personalizada com a data formatada.

## Como Executar

Estes programas podem ser executados localmente usando o **GnuCOBOL** ou em compiladores online como o **JDoodle**.

> **Nota para execução interativa (JDoodle):** Certifica-te de ativar a opção **INTERACTIVE** no painel de opções para permitir a entrada de dados do utilizador.
